# 回笺 Huijian for macOS

回笺的 macOS 接收端：常驻菜单栏，收消息、弹通知、下载附件，管理消息、频道、pushkey 和设备。需要 macOS 14+ 和 Apple Silicon。App 使用 ad-hoc 或自签名证书签名，不需要苹果开发者账号。

## 构建
    ./build.sh                                  # → build/Huijian.app（xcrun swiftc + Info.plist + codesign）
    BUNDLE_ID=com.example.huijian ./build.sh    # 自定义 Bundle ID，默认 io.github.hongyile.huijian

- 产物实际放在 `build.noindex/`（`build` 是指向它的符号链接），`.noindex` 结尾的目录不会被 Spotlight 收录，避免搜索时出现多个回笺。
- 显示名为「回笺」，可执行文件为 `Huijian`，URL Scheme 为 `huijian://msg/<id>`。
- 数据目录：`~/Library/Application Support/Huijian`（消息、已读 / 收藏）、`~/Library/Caches/Huijian`（附件缓存，位置可在设置里改）。
- 钥匙串服务名与 Bundle ID 默认值相同；UserDefaults 键统一使用 `huijian.` 前缀。
- 可选配置写在 `build.local.env`（已被 git 忽略），见 `build.sh` 开头的说明；发布用 `release.sh`（自己的服务器）和 `release_github.sh`（GitHub Releases）。

## 连接与账号
- 三种方式连接：**配对码**（管理网页「设备」页，或另一台设备的「账户」页生成；3 分钟有效、只能用一次）、**账号登录**、**注册**（服务器开放注册时）。
- 用配对码加入的账号还没有用户名密码时，主窗口只显示「完成账号设置」，设好才能使用。
- 左下角显示当前账号，点一下直接打开统一的「账户与设置」窗口：左侧依次是账户、Pushkey、通用、通知、服务器、网络，底部是打开管理后台、退出登录。账户页生成配对码后显示倒计时，被用掉后立即显示是哪台设备。暂停通知在菜单栏面板里。
- 「打开管理后台」需要本机有管理权限：在管理网页「设备」页为这台设备打开「允许管理」（默认关闭）。

## 同步方式
- **启动时**：`GET /v1/messages?since=<本地最大 id>` 补拉历史消息，不弹通知；再拉 `/v1/info`（功能清单）和 `/v1/channels`（频道设置）。
- **之后**：循环长轮询 `GET /v1/messages?since=<游标>&wait=50&changes_since=<变更游标>`。新消息弹通知；同一个响应里还带着其他设备的删除、归档和频道设置变更，立即应用。
- **设置实时同步**（服务端 0.6.1 起）：变更里还会出现 `keys` / `devices` / `account`。别的设备或管理后台新建、改名、吊销 key，设备加入、改名、被移除、管理权限改了，用户名或密码改了，本机在后台重新拉取（连续多条合并成一次），打开着的 Pushkey 页（含发送示例、本机接收方式）和账户页立即显示新数据，还没同步的 key 草稿保留；本机被移除时按「设备已失效」处理。
- **对账**：第一次启用、离线太久或服务端数据换过时，先 `GET /v1/messages/state` 对账（服务端已删除的消息从本机删掉），对账失败不影响收新消息。
- **出错时**：指数退避重试（1→30 秒）；401 停止同步并提示重新配对。
- **版本适配**：按服务端的功能清单决定功能能不能用，服务端太旧时注明「更新服务端后可用」。
- SSE 代码保留在 API.swift 里作为可选方案，默认不用：部分安全软件的 HTTPS 扫描会缓冲流式响应。

## 界面（按 ../DESIGN.md「宣纸与墨」）
- **侧边栏**
  - 收件箱：全部、未读、重要、收藏、有附件、归档。
  - 频道：每个 topic 一项。右键可以重命名（显示名）、置顶、静音、隐藏、清理、删除频道；拖动排序。隐藏的频道收在底部「已隐藏」里。
  - 底部：更新提示、账户按钮。
- **列表**：同一线程折叠成一行，用优先级色条或圆点区分轻重，P5 标题用朱砂色。
  - ↑↓ 切换；⌘ / ⇧ 点击多选，底部出现「归档 / 删除」操作条；Delete 键删除（有确认）。
  - 右键：标为已读 / 未读、收藏、复制标题、只看频道、归档 / 移回收件箱、删除。
- **详情**：优先级徽章、频道、线程、Markdown 正文、附件卡片、线程时间线；右上角「…」菜单可以归档、删除这条或整个会话。
  - 正文按服务端 0.6.0 起下发的 `doc` 绘制（和 iPhone、安卓一致）：表格（超过 200 行先显示前 200 行）、任务列表、七种提示框（可折叠）、进度条、代码块（复制、左右滚动）、脚注；`attachment:` 引用的图片直接显示在正文里（点击 QuickLook 预览），其他附件显示成附件卡片，行内附件链接显示为「📎 文字」（正在下载时等下完再打开）；外部图片点击后才加载（不带 Cookie 和登录凭据，超过 20 MB 不加载；跳转最多跟 5 次，https 跳到 http 会被拦截），加载后点击用 QuickLook 查看；`huijian://message/<id>` 在应用内跳到那条消息，本机没有时提示「消息不存在或已被删除」。连旧服务端时退回简单解析。写法见 [../docs/markdown.md](../docs/markdown.md)。
  - 绘制代码 `Sources/MDDoc.swift`、`DocView.swift`、`MDSelfTest.swift` 和 iPhone 端（ios/Sources）内容完全相同，平台相关部分在 `DocPlatform.swift`。
- **工具栏**：搜索（标题、正文、附件名、频道名）、优先级筛选、全部已读、清理消息（按频道、时间、优先级批量删除或归档）。
- **附件卡片**：未下载 / 下载中（进度环，可取消）/ 已下载（缩略图）；单击用 QuickLook 预览。
- **菜单栏面板**：最近 6 条消息（不含日志级和隐藏频道）、未读数；有未读 P5 时菜单栏图标变成朱砂色。
- **设置**（5 页）
  - 通用：登录时启动、软件更新、消息自动归档天数、附件保存位置 / 自动下载上限 / 保留时长、配置导出导入。
  - 通知：每级优先级是否弹出、是否响铃，免打扰时段，在用设备优先。
  - Pushkey：新建、改名、自定义、吊销、删除 key；本机对每把 key 的「提醒 / 静默 / 不接收」。
  - 服务器：服务端版本、存储与备份状态、立即备份。
  - 网络：HTTP / SOCKS5 代理，分别用于应用更新和服务器连接。

## 测试
- `tests/selftest.sh [IP]`：启动独立 hub（端口 28790/28791），用 `Huijian --selftest` 做命令行自检（240 余项，含应用内更新替换、删除与归档同步、频道设置、回笺 Markdown 的 doc 解码与绘制）。不弹 GUI，不碰真实的钥匙串和数据目录。
- `tests/gui_shots.sh [名称…]`：启动独立 hub 灌入演示数据（P0–P5、线程、各类附件、归档消息、频道设置），以 `--demo` 模式截图到 `screenshots/`：main-light / main-dark、panel、settings-*、archive、cleanup、channel-menu（模拟右键，需要辅助功能权限）、channel-rename、account、pair-used（生成配对码后用 curl 配对一台设备，截「已被某设备使用」）、setup、update-*、pair，以及回笺 Markdown 演示消息（`tests/markdown_demo.md`）的 markdown-light / markdown-dark / markdown-image / markdown-image-dark。
- 两个脚本都使用仓库内 `server/` 编译的 `huijian`，源码比二进制新时自动重新编译。

## 首次使用
1. 从 Releases 下载 dmg，把回笺拖进「应用程序」。第一次打开被系统拦截时，到「系统设置 → 隐私与安全性」点「仍要打开」。
2. 系统询问通知权限时选「允许」。拒绝过的话到「系统设置 → 通知 → 回笺」里打开。
3. 填服务器地址（例如 `https://push.example.com`）和 6 位配对码，或用账号登录。
4. 在「设置 → Pushkey」新建 key，交给发送方（脚本、服务器、AI agent）。
5. 建议在「设置 → 通用」打开「登录时启动回笺」。之后的版本在应用内一键更新。
