# 回笺 Huijian 界面设计规范 v2（Mac App 与管理网页共用）

> 品牌：回笺（回信的信笺）。视觉主题「宣纸与墨」：暖色宣纸底、墨色文字、靛青强调、朱砂示警。**不用纯白，不用纯黑**。
> 目标气质：安静、温润、信息密度适中、一眼分清轻重缓急。
> 不追求花哨，追求**层次**：重要的醒目，日志类的退后。

## 1. 设计令牌

### 1.1 颜色（浅色「宣纸」/ 深色「夜墨」）
| 名称 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| bg | `#F4F1EA` | `#1A1917` | 窗口/页面底色（宣纸） |
| sidebar | `#EDE9E0` | `#151412` | 侧边栏，比底色略深，和内容区分开 |
| surface | `#FBF9F5` | `#22201E` | 卡片、列表、详情（暖白，不是纯白） |
| surface-2 | `#F0ECE4` | `#2B2926` | 输入框、代码块、附件占位、悬停 |
| border | `#E1DBD0` | `#35322E` | 1px 分隔线，尽量少用，靠底色层次区分 |
| text | `#2B2924` | `#EBE6DC` | 主文字（墨） |
| text-2 | `#6A655C` | `#ABA497` | 次要文字 |
| text-3 | `#9D978C` | `#77716A` | 弱化文字（时间、大小） |
| accent | `#4A63B5` | `#8EA2EC` | 靛青：选中、主按钮、链接 |

选中态：accent-soft 底 + accent 文字，不要整行实色填充。

### 1.5 品牌
- 名称：中文「回笺」，英文 Huijian；命令行 `huijian`（建议用户自建别名 `hj`）；URL Scheme `huijian://`（改名前的 `hongyan://` 也认）。
- 图标：宣纸底（`#F4F1EA`）上一个靛青信封（`#4A63B5`，墨色描边），一道靛青箭头从左上方飞入信封（主功能：推送送达），下方一条墨色细虚线绕回（辅助功能：可以回复），信封右上角三道朱砂短线表示新消息。深色版用夜墨底（`#1A1917`）。
  - 源文件和生成脚本在 `design/icon/`：`python3 design/icon/make.py` 生成 Mac / iPhone（含深色）/ 安卓（自适应、主题单色、通知栏）/ 网页 favicon；32px 及以下自动用去掉虚线的简化版。
  - App 内的标志（iPhone 登录页、Mac 菜单栏与空列表）由 `HuijianMark.swift` 用同一组坐标绘制。

### 1.4 字体与间距
- 字体：系统字体（SF Pro / PingFang SC），等宽用 SF Mono / Menlo。
- 字号：详情标题 20 semibold；列表标题 13.5 semibold；正文 13.5；元信息 12；徽章 11。
- 间距基数 4：常用 8 / 12 / 16 / 24。圆角：卡片 10，按钮 7，徽章 4。
- 时间：列表用相对时间（刚刚 / 5 分钟前 / 14:32 / 昨天 / 11-15），详情和悬停显示完整时间 `2026-11-17 14:32:05`。
- 大小：`106 KB`、`29.3 MB`。

## 2. 信息组织原则
1. **线程优先**：同一 `thread` 的消息在列表里折叠成一行（显示最新一条 + "共 N 条"），详情里展开为时间线。没有 thread 的消息单独成行。
2. **标题和正文分开**：列表只显示标题 + 一行摘要（正文去掉 Markdown 符号后截断）。完整 Markdown 只在详情里显示。
3. **附件就近**：列表行只显示附件图标和数量；详情里是附件卡片网格。
4. **轻重有别**：P4/P5 在列表里有左侧色条；P1/P0 整行变淡。
5. **空状态要有引导**：例如没有消息时显示一段可复制的发送示例。

## 3. Mac App 布局
```
┌──────────┬────────────────────────┬───────────────────────────────────┐
│ 收件箱    │ [搜索]          [筛选▾]│ P4 重要   train · gpu-01 训练脚本   │
│  全部  12 │▌● exp42 完成     14:32 │ exp42 完成                         │
│  未读   3 │  val_loss 0.231  📎2 ▸5│ 2026-11-17 14:32:05                │
│  重要   2 │ ● 磁盘 95%       14:10 │ ───────────────────────────────── │
│  收藏   1 │  …                     │ 正文（Markdown：段落/列表/代码块） │
│  附件   4 │                        │                                    │
│ 频道      │                        │ 附件 (2)                           │
│  # train 5│                        │ ┌────────┐ ┌────────┐             │
│  # infra 1│                        │ │缩略图   │ │ PDF图标 │             │
│          │                        │ │loss.png│ │report  │             │
│          │                        │ └────────┘ └────────┘             │
│ ● 已连接  │                        │ 线程 exp42（5 条）时间线            │
└──────────┴────────────────────────┴───────────────────────────────────┘
```
- 三栏：侧边栏 200pt、列表 320pt、详情自适应；最小窗口 900×560。
- **附件卡片**：160×132，三种状态：
  - 未下载：类型色图标（40pt，置于该色 10% 底的圆角方块中）+ 文件名（两行截断）+ 大小 + 「下载」按钮。
  - 下载中：进度环 + 百分比 + 取消。
  - 已下载：图片显示缩略图铺满卡片上部；其他文件显示 QuickLook 缩略图；底部是文件名。
  - 交互：单击已下载的卡片用 QuickLook 打开；右键菜单提供 QuickLook、在 Finder 中显示、另存为、删除本地副本。
- **菜单栏面板**（MenuBarExtra `.window` 样式，宽 340）：顶部是「回笺」+ 连接状态；中间是最近 6 条消息；底部按钮：打开回笺、管理后台、暂停通知▾（1 小时 / 到明早 8 点）、设置、退出。
- **设置**（Settings 场景，三个标签）：
  - 通用：登录时启动、附件保留时长（24h / 3 天 / 7 天）、本地缓存占用 + 立即清理；
  - 通知：每个优先级是否弹出、是否响铃，免打扰时段；
  - 账户：服务器、设备名、能否进入管理后台、解除配对。
- **配对窗口**：居中卡片，App 图标、两个输入框、说明文字、错误提示。

## 4. 管理网页布局
```
┌────────────┬──────────────────────────────────────────────┐
│ ◉ 回笺     │ 概览                                          │
│            │ ┌──────┐┌──────┐┌──────┐┌──────┐             │
│ 概览        │ │今日消息││在线设备││附件占用││24h 分布│             │
│ 消息        │ └──────┘└──────┘└──────┘└──────┘             │
│ Pushkey    │ 最近消息（卡片列表）                           │
│ 设备        │                                              │
│ 设置        │                                              │
│            │                                              │
│ v0.3       │                                              │
└────────────┴──────────────────────────────────────────────┘
```
- 左侧固定导航 220px；内容区最大宽 1080px；支持深色模式（prefers-color-scheme）。
- 消息页：筛选条（优先级、频道、关键词、只看有附件），分页显示（每页 50 条），附件可直接下载。
- Pushkey 页：每个 key 一张卡片；key 默认打码，可「显示」「复制」；提供 curl / 命令行 / Python 三种示例，切换显示，一键复制。
- 设备页：平台图标、在线状态、最后在线时间（相对时间）、「可进入管理后台」开关、吊销；「添加设备」会显示大号配对码 + 倒计时。
- 设置页：已记住的浏览器（可注销）、服务信息、忘记登录时的恢复方法。
- 不引入任何外部 CSS/JS/字体；只用原生 JS 做复制、倒计时、标签切换。
