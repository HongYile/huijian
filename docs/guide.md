# 使用指南

## 优先级

发送时带 `priority`（0–5，默认 3）：

| 级 | 名称 | 效果 | 适合 |
|---|---|---|---|
| 5 | 紧急 | 弹出 + 响铃，静音、勿扰时也提醒 | 需要马上处理：任务崩溃、磁盘将满、安全告警 |
| 4 | 重要 | 弹出 + 响铃 | 在等的结果：长任务完成、关键指标出来了 |
| 3 | 普通 | 静默弹出 | 一般进展 |
| 2 | 低 | 不弹，只进列表 | 例行信息：备份成功 |
| 1 | 日志 | 不弹，列表里弱化显示 | 过程日志、心跳 |
| 0 | 调试 | 不弹 | 调试 |

每一级是否弹出、是否响铃，都可以在客户端里单独设置，也可以设定免打扰时段。

## 频道

**频道就是发送时带的 `topic` 参数**，用来给消息分类，不用事先创建。没带 `topic` 的消息进 `default` 频道。

- 按来源或用途分，例如 `train`（训练）、`infra`（服务器）、`backup`（备份）、`deploy`（部署）、`report`（报表）、`agent`（AI agent）。
- 用固定的短名字，最长 64 字节。不要把日期、任务编号放进 topic，否则频道会越来越多。一次任务的多条消息用 `thread` 区分。
- 按字面区分：`train` 和 `Train` 是两个频道。

在客户端里右键（手机上长按）频道，可以：

| 操作 | 效果 |
|---|---|
| 重命名 | 起一个好认的显示名，例如 `train` →「训练」。只改显示，发送方照旧用 `train` |
| 置顶 / 拖动排序 | 调整频道顺序 |
| 静音 | 消息照常进列表，但不弹通知、不响铃；紧急消息照常提醒 |
| 隐藏 | 消息不进收件箱、完全不提醒（紧急消息也不提醒），收在侧栏底部「已隐藏」里 |
| 删除频道 | 删除这个频道的全部消息，所有设备同步消失，不能恢复 |

这些设置保存在账号里，所有设备同步。

## 线程

同一件事的多条消息带同一个 `thread`，例如一次训练的「开始、进度、评估、完成」：

```bash
huijian push -topic train -thread exp42 -p 2 "exp42 第 10 轮"
huijian push -topic train -thread exp42 -p 4 "exp42 完成"
```

客户端会把它们折叠成一行，展开后按时间线显示。

## 附件

- 一条消息可以带多个附件，用 `-F file=@…`（curl）或 `-f`（命令行）。
- 正文里可以直接显示附件图片：`![损失曲线](attachment:loss.png)`。写法见[回笺 Markdown](markdown.md)。
- 小附件（默认 10MB 以内，可调）收到后自动下载，大文件点了再下。

## 删除与归档

- 可以删除单条消息、整个线程，或者按频道、时间批量删除；删除会同步到所有设备。
- 超过设定天数（默认 30 天）的消息自动归档，收藏的除外。

## 多设备

- 每台设备对每把 pushkey，都可以设成「提醒 / 静默 / 不接收」。
- 正在用一台设备时，其他设备的普通消息自动静默，紧急消息照常提醒。

## 发送端：两种 key

| | 加密发送密钥 | 普通 pushkey |
|---|---|---|
| 形式 | `PK_xxx.e2e.<公钥>` | `PK_xxx` |
| 怎么发 | `huijian` 命令行或 Python SDK | curl 就行 |
| 加密 | 在发送的机器上加密，服务器全程看不到内容 | 「明文发送」：服务器收到时能看到内容，随后立即加密保存 |
| 设备上的标记 | 🔒 | 「明文发送」 |

两种 key 都在客户端的 Pushkey 页复制，默认复制的是加密发送密钥。

## 给 AI agent 用

仓库里有一份 [skill 文档](../skills/huijian/SKILL.md)，教 agent（Claude Code 等）什么时候发通知、怎么选优先级、怎么带附件。安装到 Claude Code：

```bash
mkdir -p ~/.claude/skills && cp -r ../skills/huijian ~/.claude/skills/
export HUIJIAN_URL=https://push.example.com HUIJIAN_PUSHKEY=PK_xxx   # 写进 shell 配置
```

之后对 agent 说「跑完通知我」，它就会在任务结束时给你发一条。

skill 每天第一次使用前，会对照本仓库检查自己是否最新；有更新时告诉你改了什么，并自动替换。如果改动涉及把 pushkey 发到别的地址、执行新的命令或读取别的文件，agent 会停下来先问你。
